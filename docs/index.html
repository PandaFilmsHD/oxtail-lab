    ⚙️ Settings + how it works

    • A GitHub job pulls every league on your ESPN account a few times a day, grabs NFL advanced stats from nflverse, reruns everything and updates this page.
    • Player value blends season average, last 4 games, expected points from usage and ESPN's rest-of-season projection, then adjusts for usage trend and each week's matchup.
    • Matchups use schedule-adjusted fantasy points allowed, the same idea 4for4 and FantasyPros use: each defense is judged by how much more or less players score against it than they normally do, so a defense doesn't look good just because it played bad offenses.
    • Trade value works like a trade value chart: add up both sides, and the side sending more players takes a 25% tax, since 2 okay players are rarely worth 1 great one.
    • Every team starts its best lineup each week, scores swing about 24 points a week, and the bracket follows your league's playoff setup.
    • Injury guesses live in assumptions.json in the repo. Edit it on GitHub and the next update uses it.
