    How it works

    • A GitHub job pulls the league from ESPN a few times a day, then reruns everything and updates this page.
    • Player value = season average blended with the last 4 games, then moved up or down as much as 15% by how many points the opponent gives that position.
    • Every team starts its best lineup each week. Weekly scores swing about 24 points. The bracket is 6 teams, top 2 get byes, ties go to points.
    • Trades and waivers are scored on your lineup for the rest of the regular season plus the playoff weeks you'll actually play, counted double.
    • Injury guesses and value overrides live in assumptions.json in the repo. Edit that file to change them; the next update uses it.
